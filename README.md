# Журнал групи на папір

Статична сторінка: Excel (або CSV) повного журналу → прев’ю A4 → PDF.

Сервер не потрібен. Відкрий `index.html` у браузері. Якщо Excel лежить поряд зі сторінкою, зручніше підняти її через будь-який локальний http (інакше браузер може не дати прочитати файл сам).

## Як користуватись

1. Кинь **Excel повного журналу групи** (зразок — `Км-42.xlsx`).
2. Аркуші-предмети збираються в один журнал. «Коди» і «Звітність» пропускаються.
3. **Завантажити PDF** — файл на кшталт `Журнал групи КМ-42.pdf`. Друк — запасний варіант.

CSV одного предмета — «старий спосіб» під спойлером.

## Що робить верстка

- Ліва сторінка — оцінки по датах занять; тематична / семестрова / залік у сітці лишаються, але тему під них не ставимо.
- Права — стільки ж тем, скільки дат. На останній сторінці ще залік і рядки викладача («за планом…»).
- Місячні «Разом за жовтень» ігноруємо.
- Відрахування / академвідпустка розтягуються до кінця сторінки і на наступні аркуші.

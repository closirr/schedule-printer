# Журнал групи на папір

Статична сторінка: Excel повного журналу → прев’ю A4 → друк у PDF.

Сервер не потрібен. Відкрий `index.html` у Chrome.

## Як користуватись

1. **Етап 1** — обери XLS журналу групи (зразок — `Км-42.xlsx`).
2. Аркуші-предмети збираються в один журнал. «Коди» і «Звітність» пропускаються.
3. **Етап 2 — Друк** відкриває чисту вкладку й діалог. Chrome, масштаб 100%, без колонтитулів, «Зберегти як PDF».

CSV одного предмета — «старий спосіб» під спойлером.

**Зібрати журнал** — завантаж порожній шаблон електронного журналу, вкажи групу, предмети й викладачів. Сторінка збере Excel: службові аркуші з шаблону + по аркушу на кожен предмет з тією самою розміткою, що й порожній предмет у шаблоні.

## Що робить верстка

- Ліва сторінка — оцінки по датах занять; тематична / семестрова / залік у сітці лишаються, але тему під них не ставимо.
- Права — стільки ж тем, скільки дат. На останній сторінці ще залік і рядки викладача («за планом…»).
- Місячні «Разом за жовтень» ігноруємо.
- Відрахування / академвідпустка розтягуються до кінця сторінки і на наступні аркуші.
